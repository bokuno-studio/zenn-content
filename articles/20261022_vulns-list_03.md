## 要点（3行）

- 10月1日から22日までに出た脆弱性を、拾えるだけ拾ったら61件になった。
- 大手の定例の更新は、13日と20日に多く出ていた。13日が Microsoft・SAP・Adobe、20日が Oracle・Atlassian・Chrome。
- PHP と GitLab には、ログインなしでサーバーを乗っ取られる穴が出ていた。

![2026年10月1日から22日までに出た脆弱性61件を、日付で3つに分けた。1日〜7日が13件（NetScaler、Atlassian の Jira・Confluence、Android、SonicWall、VMware など）。8日〜14日が19件（Microsoft の月例更新、Ivanti、SAP、Adobe、SiteGuard、PAN-OS など）。15日〜22日が27件（PHP、GitLab、Oracle Java、Chrome、BeyondTrust、Linux カーネルなど）。ほかに、日付が1日に決まらないものが2件ある（工場や医療の制御機器、Zimbra）](/images/20261022_vulns-list_eyecatch.png)

## 発表が多すぎる

10月に入ってから、脆弱性のニュースをやたらと見る。Microsoft の月例更新は直した件数が約1,400件で過去最多だったし、20日の Oracle の定例更新では Java だけで55件が直った。21日には PHP と GitLab に、ログインなしで乗っ取られる穴が見つかっている。JVN や JPCERT/CC の一覧も毎日のように増えている。

それで、発表された日の新しい順に並べてみた。日付はそれぞれの出どころに載った日で、メーカーが発表した日とずれていることがある。22日時点でネットに出ていた記事を集めただけなので、信憑性は知らん。分からなかった欄は空けてある。表の深刻度は CVSS の点数で、10.0 が一番重い。

## 作業の前に気をつけること

:::message alert
- **SiteGuard Server Edition**：更新すると攻撃の跡が消える。上げる前に、管理画面から「診断情報」を保存しておく。
- **AhsayCBS**：先に出た修正版（v10.3.4.0 / v9.15.2.59）では直っていない。
- **GitLab**：10月12日の更新で止まっていると、10月21日の穴が残っている。
- **NetScaler**：最初に出た修正版（14.1-73.37 / 13.1-64.23）では足りない場合がある。
- **Linux（PwnEscape）**：仮想マシンの中ではなく、ホストのカーネルを上げる。
- **PHP**：PHP-FPM でも Apache の mod_php でも、動かし方を問わず対象になる。更新したあとの再起動を忘れない。
:::

## 確かめられなかったこと

- Apple と Jenkins は、10月の告知を見つけられなかった。
- Zimbra の4件は、元の告知までは見ていない。発表された日も分からなかった。
- Fortinet の複数の製品の穴（CVE-2025-61624）と Cisco Secure Email Gateway、Siemens Software Center は、どの版で直るのか分からなかった。
- 件数や版の番号は、記事によって少しずつ違っていた。作業の前にメーカーの告知で確かめてほしい。
